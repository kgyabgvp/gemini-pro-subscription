## Gemini Pro 现在对应什么产品？

“Gemini Pro”这个关键词仍然被大量使用，但 Google 的产品命名已经发生变化。现在用户通常是在 Google AI Pro 方案中获得更高等级的 Gemini 使用权限，而不是单独购买一个名为“Gemini Pro”的独立软件。

这意味着，购买前最好先确认自己的需求：

- 只是偶尔聊天、翻译和总结，免费版可能已经够用。
- 需要更高额度、复杂推理、长文档处理或更稳定的高级模型访问，Google AI Pro 更匹配。
- 需要更高使用上限、视频创作工具和更大云存储，才有必要看 Ultra。
- 如果只是为了调用 Gemini API，则应该研究 Google AI for Developers 的 API 计费，而不是购买 Google AI Pro。订阅会员和 API 余额不是同一套计费体系。

WildAI 帮助中心给出的 Gemini 订阅流程大致分为三步，整体通常需要在电脑浏览器中完成。

进入订阅页面后，选择 Gemini 卡片，再选择 Plus、Pro、Ultra 5x 或 Ultra 20x。

### 2. 登录 Google 账号并提交 Cookie

WildAI 的 Gemini 教程说明，用户需要在同一个 Chrome 浏览器中登录自己的 Google 账号，然后使用 Cookie-Editor 扩展导出 Cookie JSON，再提交到订阅页面。

这里有几个风险点必须提前知道：

- Cookie JSON 相当于登录凭证，不是普通验证码。
- 不要把 Cookie 发给无关人员，也不要粘贴到其他网站。
- 应该只在官方流程要求的页面中提交。
- 不建议使用公共电脑完成操作。
- 完成订阅后，应检查账号安全设置和登录活动。

WildAI 的帮助中心还提到，Cookie 需要在电脑端获取，手机端无法完成这一流程。若插件导出的内容不完整，或者不是在正确的 Google 页面导出，验证可能失败。

### 3. 付款并等待开通

Cookie 验证通过后，页面会进入收银台。付款完成后，订单状态可能先显示为处理中，通常需要等待一段时间。

WildAI 的 Gemini 教程写明，付款后一般约 **5 至 30 分钟**完成开通；如果订单超过正常时间仍没有变化，应先在订单页查看状态，不要连续重复付款。

如果平台显示已完成，但 Gemini 页面仍显示 Free，可以按以下顺序排查：

1. 确认登录的是提交订阅时使用的同一个 Google 账号。
2. 退出 Gemini 后重新登录。
3. 强制刷新订阅页面。
4. 检查账号地区是否支持对应 Gemini 方案。
5. 保存订单号、付款记录和订阅页面截图，再联系客服处理。
